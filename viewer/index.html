Open the viewer with the launcher

Browsers block this page when it's opened straight from a file.

Install the TaleSpire Map Viewer app, or on a Mac double-click open-viewer.command in the TS_MAP folder. Anywhere else, run python3 -m http.server 8765 in the TS_MAP folder and visit http://localhost:8765/viewer/.

Load a TaleSpire map

  1. First time? Click Install TaleSpire mod below. It sets up the exporter in TaleSpire for you.
  2. In TaleSpire, open your board and press Ctrl+Shift+E. To export only part of the board, select that area with TaleSpire's selection tool first.
  3. Drag the new file from Documents/TaleSpireMapExporter onto this window (or use Load export…).
  4. Click Open latest export. New exports also pop up a notice here as soon as you make them.
  5. Shape it: Select and remove walls or roofs, cut the sides and height, then explore with the Token.
