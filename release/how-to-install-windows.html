TaleSpire Map Tools

Install on Windows 10/11 (64-bit). About 5 minutes, once per PC.

You install one app, TaleSpire Map Viewer. It then installs its companion TaleSpire mod for you. The mod adds Ctrl+Shift+E to TaleSpire to export the board you're on. The app lets you shape that map, explore it (as a map or as Cyberpunk-style netspace), walk a token on the grid, and keep notes.

First: right-click the downloaded .zip → Extract All….

1 Install the app

  1. Open the 1 - Viewer app folder and double-click TaleSpire Map Viewer_…_x64-setup.exe.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway. The app isn't signed with a paid certificate, so SmartScreen doesn't recognise it.
  3. Follow the installer. It installs just for you, so no admin rights are needed. It adds a Start-menu entry and installs Microsoft WebView2 if your PC doesn't have it yet.

2 Install the TaleSpire mod, from the app

  1. Close TaleSpire if it's running.
  2. In the app, click Install TaleSpire mod (on the start screen, or TaleSpire mod… in the side panel).
  3. It finds TaleSpire in your Steam libraries on any drive (Detect). If it can't, use Browse… and pick the TaleSpire folder, the one with TaleSpire.exe (Steam → right-click TaleSpire → Manage → Browse local files shows it).
  4. Click Install mod. The app downloads the mod loader (BepInEx, checked), installs it, and installs the mod. Every line turns ✓.

On Windows there's nothing to set in Steam: start TaleSpire as usual.

Using r2modman or Thunderstore? Those run mods from your r2modman profile. After installing, copy BepInEx\plugins\TaleSpireMapExporter from the TaleSpire folder into the profile's BepInEx\plugins folder.

3 Use it

  1. Start TaleSpire, open a board, and press Ctrl+Shift+E. A message at the top of the screen confirms the export. To export only part of the board, select that area with TaleSpire's selection tool first.
  2. In the app, click Open latest export.
  3. Tools: 1 look · 2 select and remove pieces · 3 token (click floors to walk; V for first person) · 4 notes. Use G to switch styles, including Cyberspace. WASD/Q E/R F move the camera.

When you get a newer version of the app, open TaleSpire mod… and click Update mod.

Installing the mod without the app

The Manual mod install (optional) folder has an installer that does the same thing: close TaleSpire and double-click Install mod.bat (if SmartScreen appears: More info → Run anyway). If it can't find TaleSpire, run .\install-windows.ps1 -GamePath "D:\…\TaleSpire" in PowerShell from that folder.
