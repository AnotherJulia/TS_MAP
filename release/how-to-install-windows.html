TaleSpire Map Tools

Install on Windows 10/11 (64-bit). Two parts, about 5 minutes, once per PC.

This package has two parts:

  • 1 · TaleSpire mod: runs inside TaleSpire and exports the board you're on with Ctrl+Shift+E.
  • 2 · Viewer app: opens those exports. You can shape the map, explore it as a map or as Cyberpunk-style netspace, walk a token on the grid, and keep notes.
First: right-click the downloaded .zip → Extract All…. The installers don't work from inside the zip.

1 Install the TaleSpire mod

  1. Close TaleSpire if it's running.
  2. Open the 1 - TaleSpire mod folder and double-click Install mod.bat.
    If Windows shows "Windows protected your PC": click More info → Run anyway. The installer isn't signed with a paid certificate, so SmartScreen doesn't recognise it.
  3. The installer finds TaleSpire in your Steam libraries (any drive), installs BepInEx (the mod loader, downloaded and checked), and installs the mod. It ends with Done!; press any key to close it.
  4. Start TaleSpire from Steam as usual. On Windows there's nothing to set in Steam.
If TaleSpire isn't found automatically, open PowerShell in the mod folder and pass the game folder: 
.\install-windows.ps1 -GamePath "D:\SteamLibrary\steamapps\common\TaleSpire"
(Steam → right-click TaleSpire → Manage → Browse local files shows the folder.)
Using r2modman or Thunderstore? Those run mods from your r2modman profile. After installing, copy BepInEx\plugins\TaleSpireMapExporter from the game folder into the profile's BepInEx\plugins folder.

2 Install the viewer app

  1. Open the 2 - Viewer app folder and double-click TaleSpire Map Viewer_…_x64-setup.exe.
  2. If SmartScreen appears, click More info → Run anyway (same reason as above).
  3. Follow the installer. It installs just for you, so no admin rights are needed, and adds a Start-menu entry. If your PC doesn't have Microsoft WebView2 yet, the installer adds it.

3 Use it

  1. In TaleSpire, open a board and press Ctrl+Shift+E. A message at the top of the screen confirms the export. To export only part of the board, select that area with TaleSpire's selection tool first.
  2. In the viewer, click Open latest export.
  3. Tools: 1 look · 2 select and remove pieces · 3 token (click floors to walk; V for first person) · 4 notes. Use G to switch styles, including Cyberspace. WASD/Q E/R F move the camera.

? If something doesn't work

ProblemFix
Ctrl+Shift+E does nothingIn the game folder, BepInEx\LogOutput.log should contain "TaleSpire Map Exporter … loaded". No log at all means BepInEx isn't loading: check that winhttp.dll is next to TaleSpire.exe (antivirus sometimes removes it), then run Install mod.bat again.
Where are the exports?Documents\TaleSpireMapExporter (the viewer's Show exports folder button opens it)
Remove the modIn PowerShell in the mod folder: .\install-windows.ps1 -Uninstall (add -RemoveBepInEx to remove the loader too). Remove the viewer from Settings → Apps.
