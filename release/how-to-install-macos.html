TaleSpire Map Tools

Install on macOS (Apple Silicon and Intel). Two parts, about 5 minutes, once per Mac.

This package has two parts:

  • 1 · TaleSpire mod: runs inside TaleSpire and exports the board you're on with Ctrl+Shift+E.
  • 2 · Viewer app: opens those exports. You can shape the map, explore it as a map or as Cyberpunk-style netspace, walk a token on the grid, and keep notes.

1 Install the TaleSpire mod

  1. Quit TaleSpire if it's running.
  2. Open the 1 - TaleSpire mod folder, right-click Install mod.command → Open, then click Open again.
    Why right-click? The installer isn't signed by an Apple developer, so a plain double-click is blocked the first time. Right-click → Open lets you allow it.
  3. A Terminal window runs the installer. It downloads BepInEx (the mod loader) into TaleSpire's game folder, checks it, and installs the mod. At the end it prints one line to copy, like: 
    "/Users/you/Library/Application Support/Steam/steamapps/common/TaleSpire/run_bepinex.sh" %command%
  4. In Steam, right-click TaleSpire → Properties → General → Launch Options and paste that line. You only do this once.
  5. Start TaleSpire from Steam as usual.
Apple Silicon: the launcher starts TaleSpire through Rosetta (as an Intel app), because the mod loader can't run in native Apple Silicon games. It runs a little slower but works. If macOS asks to install Rosetta, say yes.

2 Install the viewer app

  1. Open the 2 - Viewer app folder and double-click the .dmg.
  2. Drag TaleSpire Map Viewer into Applications.
  3. The first time, right-click the app in Applications → Open → Open (it isn't signed by an Apple developer either). After that it opens normally.
If macOS says the app "is damaged" or can't be opened, run this once in Terminal, then open it again: 
xattr -dr com.apple.quarantine "/Applications/TaleSpire Map Viewer.app"

3 Use it

  1. In TaleSpire, open a board and press Ctrl+Shift+E (the Control key, not Command). A message at the top of the screen confirms the export. To export only part of the board, select that area with TaleSpire's selection tool first.
  2. In the viewer, click Open latest export.
  3. Tools: 1 look · 2 select and remove pieces · 3 token (click floors to walk; V for first person) · 4 notes. Use G to switch styles, including Cyberspace. WASD/Q E/R F move the camera.
