TaleSpire Map Tools

Install on macOS (Apple Silicon and Intel). About 5 minutes, once per Mac.

You install one app, TaleSpire Map Viewer. It then installs its companion TaleSpire mod for you. The mod adds Ctrl+Shift+E to TaleSpire to export the board you're on. The app lets you shape that map, explore it (as a map or as Cyberpunk-style netspace), walk a token on the grid, and keep notes.

1 Install the app

  1. Open the 1 - Viewer app folder and double-click the .dmg.
  2. Drag TaleSpire Map Viewer into Applications, then open it.
  3. The first time, macOS says it "could not verify" the app, because it isn't notarized by Apple. Click Done, then open System Settings → Privacy & Security, scroll down, click Open Anyway next to "TaleSpire Map Viewer was blocked", and confirm. You only do this once.
Shortcut: instead of the Settings steps, run this once in Terminal, then open the app (this also fixes a "the app is damaged" message): 
xattr -dr com.apple.quarantine "/Applications/TaleSpire Map Viewer.app"

2 Install the TaleSpire mod, from the app

  1. In the app, click Install TaleSpire mod (on the start screen, or TaleSpire mod… in the side panel).
  2. It finds your TaleSpire install automatically (Detect). If you keep games somewhere unusual, use Browse… and pick the TaleSpire folder (Steam → right-click TaleSpire → Manage → Browse local files shows where it is).
  3. Click Install mod. The app downloads the mod loader (BepInEx, checked), sets it up, and installs the mod.
  4. One step in Steam: click Copy next to the launch option the app shows. In Steam, right-click TaleSpire → Properties → General → Launch Options, paste, and close the window. The app shows a ✓ once Steam has it.
Apple Silicon: with the mod, TaleSpire starts through Rosetta (as an Intel app), because the mod loader can't run in native Apple Silicon games. It runs a little slower but works. If macOS asks to install Rosetta, say yes.

3 Use it

  1. Start TaleSpire from Steam, open a board, and press Ctrl+Shift+E (the Control key, not Command). A message at the top of the screen confirms the export. To export only part of the board, select that area with TaleSpire's selection tool first.
  2. In the app, click Open latest export.
  3. Tools: 1 look · 2 select and remove pieces · 3 token (click floors to walk; V for first person) · 4 notes. Use G to switch styles, including Cyberspace. WASD/Q E/R F move the camera.

When you get a newer version of the app, open TaleSpire mod… and click Update mod.

? If something doesn't work

ProblemFix
Ctrl+Shift+E does nothingOpen TaleSpire mod… in the app: every line should show ✓. Make sure you start TaleSpire from Steam (the launch option only applies there). In the game folder, BepInEx/LogOutput.log should contain "TaleSpire Map Exporter … loaded".
"Apple could not verify…"That's macOS blocking unsigned downloads. Use System Settings → Privacy & Security → Open Anyway (or the Terminal shortcut in step 1).
Where are the exports?Documents/TaleSpireMapExporter (the app's Show exports folder button opens it)
Remove the modTaleSpire mod… → Remove mod, and clear the Steam launch option.
Installing the mod without the app

The Manual mod install (optional) folder has a script that does the same thing. Open Terminal, type bash and a space, drag install-mac.sh from that folder into the window, and press Return. Then paste the Steam launch option it prints, as in step 2.
